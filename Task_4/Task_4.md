# 📖 Overview
# This task focuses on analyzing a survey dataset and creating 
# a visual summary dashboard. Instead of working with long tables 
# and complex outputs, the goal was to build clear, short, and 
# readable insights using Python visualization libraries.

# 🎯 Objectives
# - Clean and process the dataset
# - Extract Top 5 insights from key survey questions
# - Visualize results in a clear and engaging way
# - Use short labels for better readability

# 📊 Dashboard Highlights
# The dashboard includes:
#   • Top 5 Programming Languages
#   • Top 5 Job Titles
#   • Top 5 Countries
#   • Top 5 Education Levels
#   • Top 5 Salary Brackets
#
# Each chart is designed with:
#   - Shortened axis labels
#   - Count values annotated on bars
#   - A clean Seaborn + Matplotlib layout

# 🛠️ Tools & Libraries
# - Python
# - Pandas → Data cleaning & processing
# - Seaborn → Visualization styling
# - Matplotlib → Plot customization

# ✨ Key Learning
# - Summarized large datasets into simple visuals
# - Learned to present insights clearly at a glance
# - Improved dashboard design for quick communication
