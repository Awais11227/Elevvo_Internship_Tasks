# 📊 Task 4 – Survey Insights Dashboard
 ============================================================

# 📌 Overview
- This task focuses on analyzing a survey dataset and building 
- a visual summary dashboard. The goal was to transform large, 
- complex tables into clear and easy-to-read insights using 
- Python visualization libraries.

# 🎯 Objectives
  - Clean and preprocess the dataset
  - Extract Top 5 insights from key survey questions
  - Visualize results in an engaging and readable way
   - Use short labels for better clarity

# 📈 Dashboard Highlights
# The dashboard summarizes:
   • Top 5 Programming Languages
   • Top 5 Job Titles
   • Top 5 Countries
   • Top 5 Education Levels
   • Top 5 Salary Brackets

# Each visualization was designed with:
   - Shortened axis labels
   - Count values displayed on bars
   - A clean Seaborn + Matplotlib layout

# 🛠️ Tools & Libraries
 - Python
 - Pandas → Data cleaning & preprocessing
 - Seaborn → Visualization styling
 - Matplotlib → Plot customization

# ✨ Key Learnings
 - Learned to summarize large datasets into simple visuals
 - Improved ability to present insights clearly at a glance
 - Designed dashboards that communicate findings effectively
